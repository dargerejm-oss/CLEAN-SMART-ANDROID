# CLEAN SMART

Appli Android native (Kotlin + Jetpack Compose) de JM.DARGERE pour libérer de l'espace, simplement.

- **Photos et vidéos** : doublons, photos similaires en rafale (la plus nette est gardée), captures d'écran,
  grosses vidéos, médias WhatsApp. Tout part dans la corbeille de la Galerie (récupérable 30 jours).
- **Contacts** : doublons (même nom + même numéro).
- **Mails (IMAP)** : newsletters, gros mails, vieux mails → corbeille de la messagerie. Mot de passe chiffré sur le téléphone.
- **Sauvegarde** : vers un dossier choisi (carte SD, clé USB, Google Drive), automatique avant chaque suppression.
- **Mode d'emploi intégré** en français et en anglais (`app/src/main/assets/manuel_fr.pdf` / `manuel_en.pdf`,
  sources : `store/manuel/make_manual.py`).
